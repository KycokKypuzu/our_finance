# Мои финансы + Умный дом

Небольшое приложение FastAPI для двух пользователей. Финансовые отчёты и управление устройствами Яндекса работают в одном процессе. База данных, очереди и отдельные сервисы не нужны.

## Запуск

Нужен Python 3.11 или новее. Команды выполнять **в каталоге проекта**, где лежит `app.py`.

**Windows (PowerShell):**

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python -m uvicorn app:app --reload --port 8000
```

**Linux / OpenWrt** (при уже установленном подходящем Python и зависимостях):

```bash
python3 -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
python -m uvicorn app:app --host 0.0.0.0 --port 8000
```

Открыть http://127.0.0.1:8000 . Для разработки доступно http://127.0.0.1:8000/docs . На роутере использовать команду без `--reload`: автоматическая перезагрузка удаляет несохранённые черновики.

## Что умеет

- `/` — выбор раздела, `/finance` — выбор/ввод пользователя, `/home` — личная страница.
- `/new` — загрузить CSV или XLSX, сопоставить столбцы, проверить операции, добавить ещё банк и сохранить отчёт.
- `/finances` — список отчётов; `/finance/{month}/{year}` — просмотр; рядом доступны анализ и редактирование.
- `/devices` — просмотр устройств Яндекс Умного дома и включение/выключение через его API.

Адреса, формы и существующие HTML-шаблоны сохранены.

## Структура кода

```text
app.py                    # Сборка FastAPI, middleware и роутеров
config.py                 # Пути к данным, общие Jinja2-шаблоны
storage.py                # Чтение/запись JSON отчётов и users.json
routers/
  pages.py                # Выбор раздела, пользователь, главная
  imports.py              # Загрузка выписки, черновик, сохранение
  reports.py              # Просмотр, редактирование и анализ
  devices.py              # HTTP-маршруты умного дома
services/
  statement_import.py     # Чтение CSV/XLSX и разбор операций
  finance.py              # Объединение банков, сохранение правок, расчёты
  drafts.py               # Черновики в памяти процесса
  yandex_api.py           # Запросы к API Яндекса
 data/                    # Пользовательские JSON (НЕ стирать)
 templates/               # HTML, CSS/JS в шаблонах
 static/                  # Картинки и favicon
```

Чтобы добавить страницу, обычно достаточно создать функцию в подходящем файле `routers/`; если появятся вычисления — вынести их в `services/`. Доступ к файлам отчётов оставлять в `storage.py`.

## Данные и совместимость

**Формат хранения не менялся.** Все финансовые отчёты по-прежнему лежат в `data/<пользователь>_<месяц>_<год>.json`, а список имён — в `data/users.json`. При добавлении банка к сохранённому месяцу обновляются только данные этого банка. Исходные файлы в `data/` перед обновлением на роутере обязательно сохранить в резервную копию.

Черновики текущей загрузки и редактирования живут только в RAM, не попадают в cookie и не сохраняются между перезапусками. Поэтому во время незавершённой загрузки не перезагружайте сервер; используйте один процесс Uvicorn (без `--workers`).

## Яндекс Умный дом

Токен читается из переменной окружения `YANDEX_TOKEN` или из `.env` в каталоге проекта:

```dotenv
YANDEX_TOKEN=ваш_токен
```

Если токена нет или API Яндекса не отвечает, страницы финансов продолжают работать. **Не публикуйте `.env` в Git или открытом архиве.**

## Важные ограничения

Прежний механизм выбора пользователя — это **не полноценная авторизация с паролем**. Приложение рассчитано на доверенных людей в локальной сети. Не выставляйте его напрямую в публичный интернет без отдельной защиты. При редактировании JSON вручную сохраняйте текущие имена полей и вложенность.
