# IoT Home + Мои финансы

Единое FastAPI-приложение. Финансовые маршруты сохранены, IoT добавлен под `/devices`.

## Маршруты

- `/` — вход в финансовую часть
- `/home` — главная страница после входа
- `/finances` — сохранённые финансовые отчёты
- `/new` — новая финансовая запись
- `/devices` — устройства Яндекс Умного дома

## Запуск

```bash
source .venv/bin/activate
python -m uvicorn app:app --host 0.0.0.0 --port 8000
```

Для разработки:

```bash
python -m uvicorn app:app --reload
```

## Yandex Smart Home

Создайте `.env`:

```env
YANDEX_TOKEN=your_token
```

Не удаляйте существующую папку `data/` при установке на роутер: в ней находятся финансовые JSON-файлы.

## Важно при обновлении на роутере

Сделайте резервную копию `data/` перед заменой файлов проекта. Затем замените код и шаблоны, сохранив старую `data/`.

IoT использует те же `aiohttp`/`python-dotenv` зависимости, что указаны в `requirements.txt`.
